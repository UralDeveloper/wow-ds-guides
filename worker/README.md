# Worker: фронт + комнаты синхронизации

- `/ws?room=<id>` — WebSocket-комната. Один Durable Object на комнату, сообщения пересылаются
  всем участникам, кроме отправителя. При обрыве соединения остальным уходит `bye`.
- Остальные пути — статика из `front/` (binding `ASSETS`).

Пустые комнаты засыпают (WebSocket Hibernation API) и не тратят лимит бесплатного тарифа.
Входящие сообщения WebSocket тарифицируются 20 к 1: 100 сообщений = 5 запросов.

Конфиг — `wrangler.toml` в корне репозитория. Деплой и подключение — корневой `README.md`.
